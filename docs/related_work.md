# Related work notes for BeliefSpec

Access date: 2026-10-01. Sources used here are primary or upstream sources: arXiv records, arXiv paper HTML, the official AgentSpec repository, the MiniGrid documentation, and Professor Qin's public Q-Lab page. These notes are for internal research positioning, not a claim of novelty.

## Narrow positioning

BeliefSpec asks: under what controlled conditions does predictive supervision make an agent's memory more useful for decisions?

This is narrower than the cited world-model and agent-scaffold papers. It does not claim that predictive memory, world models, recurrent belief states, or auxiliary prediction losses are new. The intended contribution of the pilot is an interpretable, local comparison between matched memory systems in a small partially observed task, with and without an auxiliary action-conditioned prediction loss.

## Synthesis for the pilot

The main external lesson is cautionary, not promotional. Prior work supports the broad idea that predictive objectives can shape latent belief states, but it also shows that the target and horizon matter. Short-horizon local prediction may not require retaining the clue needed for a delayed decision. Therefore, the BeliefSpec pilot should report decision success by measured clue delay, never-observed controls, prediction error, and clue-recovery quality. Lower prediction error alone should not be treated as evidence of more useful memory.

AgentSpec is the best lab-specific connection because it studies controlled composition of embodied-agent modules and memory/reasoning interactions. The BeliefSpec pilot is best described as standalone unless a documented AgentSpec example is actually run and integrated. Running an AgentSpec smoke example would not reproduce the AgentSpec paper.
